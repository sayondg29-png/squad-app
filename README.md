
# 🚀 Squad — Know where they are. Know who owes what.

> The ultimate friend group app. One place to track 
> who's late, split expenses, and know where your 
> squad is — all in real time.

---

## ✨ Features

### 📍 Live Location (Coming Soon)
- See friends as live pins on a map
- Real-time ETA and distance from meetup point
- Full privacy control — stop sharing anytime

### 💸 Expense Splitter
- Add group expenses and split them fairly
- See exactly who owes who and how much
- Mark debts as settled with one tap
- Running balance for every squad member

### 🏆 Late-O-Meter
- Log every late incident with minutes and reason
- Leaderboard ranking the most chronically late friend
- Fun badges like Chronically Late and Always On Time
- Because accountability should be fun 😄

### 📍 Check-In Status
- Set your arrival status in one tap
- I'm Here / On My Way / Running Late / Not Coming
- Squad sees everyone's status live on dashboard

### 👤 Profile System
- Sign in with Google — no password needed
- Upload a profile picture or use initials avatar
- Personal stats — late score, balance, squad rank
